# One Heart + Sarcastabastard Store

Private development repository for two distinct clothing brands and a shared T-shirt design generator.

## Brand storefronts
- **One Heart:** warm, elegant apparel; ruby-heart identity; approved small-front/large-back placement and tapered line treatment.
- **Sarcastabastard:** original, provocative adult-humour apparel; each graphic must be distinctive rather than a repeated template. Artwork placement should remain proportionate to the shirt.

## T-shirt design generator
- Choose brand, garment and print location.
- Compose original slogan and artwork as separate layers.
- Adjust artwork scale, position and print bounds without changing the artwork itself.
- Preview front and back on mobile and desktop.
- Save drafts and export production-ready artwork after print-provider specifications are confirmed.

## Store requirements
- Separate brand navigation and product catalogues; shared cart and order infrastructure.
- Product publishing requires verified artwork rights, supplier availability, pricing, fulfilment and shipping.
- Checkout stays in test mode until payment and fulfilment are verified.
- Mobile-first accessibility, responsive layouts and clear customer flows.
- No GitHub Actions, deployments, paid services or live sales until separately configured and verified.

## Development sequence
1. Build mobile-first brand landing pages and a working design studio prototype.
2. Add catalog/product detail pages and persistent cart.
3. Integrate verified products, print fulfilment and test checkout.
4. Run local browser and purchase-flow tests before deployment.
